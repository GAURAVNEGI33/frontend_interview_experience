## Round 2 — HR + Technical Round (~50 min)

### Part A: Introduction & Project Demo

- Gave a self-introduction
- Explained my **FitTrack AI** project in detail
- Did a **live demo** — ran the project and walked them through the working app

### Part B: Technical Questions

**HTML**

- Semantic tags — why they matter over generic `div`/`span`
- Difference between `id` and `class`

**CSS**

- Box model explained
- Flexbox — when and where to use it (practical use-cases, not just theory)

**JavaScript**

- Callback functions
- Callback hell — what causes it and why it's a problem
- Promises
- `async`/`await`

**Framework**

- Asked which framework I use — Angular or React?
- Mentioned that their company's projects are built in **Next.js**

**Backend / Auth Concepts**

- JWT (JSON Web Token) — its flow, how authentication works with it
- Is HTTP stateless? Why?

### Part C: Live Coding

- Asked to **write a function**
- Asked to **implement a callback function** live
- Asked to **write an example of callback hell**

### Part D: Behavioral / HR Questions

- Standard behavioral questions (my tutor had prepped me on likely topics, and most of what came up matched that prep)
- At the end, was asked if **I had any questions for them** — I asked:
  - About the company and its growth plans
  - How I could grow within the company/role

---

## 💡 Key Takeaways

- **Projects matter a lot** — being able to explain your project clearly and demo it live made a strong impression. Don't just list projects on your resume, be ready to run and explain them on the spot.
- **JS fundamentals are non-negotiable** — callback → callback hell → promises → async/await is a very common progression asked in frontend interviews. Know _why_ each concept exists, not just the syntax.
- **Be ready to write code live**, even in a role that's mostly "frontend." They wanted to see actual hands-on ability, not just theory.
- Practical framing matters — e.g., not just "what is flexbox" but "when do you use it."
- **Know the company's tech stack if you can** — even if I used React, knowing that they use Next.js showed I could research and adapt.
- **Backend-adjacent knowledge helps frontend candidates stand out** — JWT flow and HTTP statelessness aren't strictly "frontend" topics, but understanding them shows full-stack awareness.
- **Structured behavioral prep pays off** — going through likely behavioral questions beforehand (with my tutor) meant I wasn't caught off guard.
- **Always ask questions back** — asking about company growth and my own growth path showed genuine interest, not just "getting through" the interview.

## 🛠 Topics to Prepare (if you have an interview coming up)

- [ ] Semantic HTML tags and their purpose
- [ ] `id` vs `class`
- [ ] CSS Box Model
- [ ] Flexbox (practical use-cases)
- [ ] JS Callback functions
- [ ] Callback hell (and how to avoid it)
- [ ] Promises
- [ ] async/await
- [ ] Be ready to explain + live-demo your own projects
- [ ] Know differences between major frontend frameworks (React vs Angular vs Next.js)
- [ ] JWT — what it is, its flow, use cases
- [ ] HTTP statelessness — why and how sessions/tokens solve it
- [ ] Common behavioral/HR questions (strengths, weaknesses, why this company, etc.)
- [ ] Prepare 2-3 good questions to ask the interviewer at the end
